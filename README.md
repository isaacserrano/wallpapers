# Wallpapers Collection for macOS & Linux

A curated collection of high-quality wallpapers optimized for **macOS** and **Linux** desktop environments.  
This repository is intended for clean installations, theming setups, and consistent visual branding across systems.

---

## Repository Purpose

This repository provides:

- Wallpapers tailored for **macOS** (Retina / HiDPI)
- Wallpapers optimized for **Linux** desktop environments
- Multiple aspect ratios and resolutions
- Organized structure for easy browsing and automation
- A lightweight, dependency-free asset repository

The collection is suitable for:
- Fresh OS installations
- Desktop theming
- Window managers (i3, sway, bspwm, hyprland)
- GNOME, KDE Plasma, XFCE, Cinnamon, and others
- Multi-monitor setups

---

## Supported Platforms

### macOS
- macOS Sonoma and newer
- Retina and non-Retina displays
- Light and dark themes (where applicable)

### Linux
- GNOME
- KDE Plasma
- XFCE
- Cinnamon
- i3 / sway / hyprland
- Wayland and X11 environments

## Image Specifications

All wallpapers aim to meet the following guidelines:

- **Formats**: PNG, JPG/JPEG (no proprietary formats)
- **Color Space**: sRGB
- **Compression**: Lossless or visually lossless
- **Orientation**: Landscape preferred
- **No watermarks**
- **No embedded metadata that tracks users**

---

## Common Resolutions

- 1920×1080 (Full HD)
- 2560×1440 (QHD)
- 3840×2160 (4K)
- 5120×2880 (5K)
- 3440×1440 (Ultrawide)
- 5120×1440 (Super Ultrawide)
